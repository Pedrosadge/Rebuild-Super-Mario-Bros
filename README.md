Deskripsi Proyek

Proyek ini bertujuan untuk membuat ulang game Mario menggunakan bahasa pemrograman Java. Tujuan dari proyek ini adalah untuk menguji apakah konsep pembuatan game ini dapat diterapkan pada game lain dengan bahasa pemrograman yang berbeda.

Cara Menjalankan Program

Buka folder src

Buka folder main

Buka file Main.java

Jalankan program
